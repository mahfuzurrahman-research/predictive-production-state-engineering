# Engineering scope and disclosure boundary

## Publicly demonstrated

- temporal/as-of validation
- synthetic forecast-pair construction
- deterministic benchmark interfaces
- standard forecast metrics
- DuckDB relational modeling and marts
- executable SQL QA
- atomic writes and SHA-256 receipts
- interruption/resume handling
- tests, CI and Docker
- automated reporting and dashboard generation
- fitted ridge and random-forest models on an independent fabricated panel
- expanding-window selection with target-label availability checks
- separate later calibration and frozen holdout evaluation
- input, label-quality, error and interval monitoring
- saved-model replay and independent feature/metric reconstruction

## Intentionally excluded

- protected research data or values
- archived private forecast pairs
- protected/reserve evaluation results
- historical research engines and scorers
- exact private model selection or retuning logic
- private provenance archives
- unpublished manuscript text and submission material

This repository demonstrates engineering capability; it is not a scientific replication package.

The new target is an arbitrary fabricated index. No measured agricultural or
fiscal outcome enters this public workflow. Monitoring alerts request review;
they do not establish a causal regime change or authorize automatic retraining.
Successful execution is not evidence of real forecasting accuracy, production
deployment, scientific identification or private-study validity. Supported CV
claims must retain the synthetic scope.
