# Engineering scope and disclosure boundary

## Publicly demonstrated

- temporal/as-of validation
- synthetic forecast-pair construction
- deterministic benchmark interfaces
- standard forecast metrics
- DuckDB relational modeling and marts
- executable SQL QA
- atomic writes and SHA-256 receipts
- interruption/resume handling
- tests, CI and Docker
- automated reporting and dashboard generation

## Intentionally excluded

- protected research data or values
- archived private forecast pairs
- protected/reserve evaluation results
- historical research engines and scorers
- exact private model selection or retuning logic
- private provenance archives
- unpublished manuscript text and submission material

This repository demonstrates engineering capability; it is not a scientific replication package.
